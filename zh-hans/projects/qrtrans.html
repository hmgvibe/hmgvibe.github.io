QRTrans

用 QR Code 和相机，在没有网络时发送数据。

文件传输 · Android · Windows

QRTrans 将单一文件或文字转为持续变化的 QR Code，接收设备用相机扫描画面，还原并验证内容。传输通过屏幕与相机完成，不需要网络路径、账号、配对或云端服务。

功能特色如何开始系统需求常见问题

01

适合哪些使用情境？

适合设备无法创建网络连接、希望避免云端中转，或需要通过屏幕向 Android 设备发送文件的情境。

02

功能特色

  • 文件与文字

    可发送最大 64 MB 的单一文件，或 UTF-8 文字内容。

  • Android 与 Windows

    Android 支持发送与接收；Windows 支持发送，可将数据送到 Android。

  • 从中途开始扫描

    QR Code 持续轮播，接收端不需要等候发送端重新开始。

  • 修复缺失数据

    喷泉码搭配修复帧，容忍丢帧、重复帧与乱序帧。

  • 可调显示方式

    同时显示 1、2 或 4 个 QR Code，并调整 10–60 FPS 的显示频率。

  • 可选密码保护

    以 Argon2id 与 XChaCha20-Poly1305 保护传输内容；使用 SHA-256 检查数据完整性。

03

如何开始

  1. 安装适合平台的版本

    从 GitHub Releases 下载 Android 或 Windows 版本，准备一台可发送的设备和一台 Android 接收设备。

  2. 选择要发送的内容

    在发送端选择单一文件或输入文字；需要保护内容时启用密码。

  3. 显示并扫描 QR Code

    让发送端开始轮播，接收端打开相机对准画面。可依扫描情况调整 QR Code 数量与显示频率。

  4. 等待还原与验证

    持续扫描直到数据完整，依接收流程完成解密并取得内容。

04

系统需求

Android
Android 7.0 / API 24 或以上，支持发送与接收。
Windows
Windows 10 build 19041 或以上，x64，仅支持发送。
接收环境
Android 设备需可用相机与相机权限，能清楚拍到发送画面。

05

常见问题

没有 Wi-Fi 或蓝牙也能使用吗？

可以。文件与文字经由 QR Code 画面发送，不使用网络连接或蓝牙配对。

没有设置密码时，旁人能读取数据吗？

未加密的 QR Code 可被对准屏幕的相机读取。敏感内容请启用密码保护，加密涵盖文件名与媒体类型。

可以和 decimen.app 互传吗？

不可以。QRTrans 的 Android 与 Windows 版本使用独立的 QRT1 协议，彼此可互传，但不兼容 decimen.app。
