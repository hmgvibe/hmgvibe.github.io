Secondary

把第二个屏幕变成自己的桌面控制中心。

桌面工具 · Windows 11 · Linux（Ubuntu／GNOME）

Secondary v1.2.0 是 Windows 11 与 Ubuntu／GNOME Linux 的副屏应用程序，集成可编辑的首页组件、分组快捷导航与游戏监测。没有副屏时，也能在另一台 Windows 或 Linux 设备运行 Secondary，通过局域网连接主电脑的“连接助手”，查看监测数据、控制媒体与运行已确认的捷径。

功能介绍如何开始系统需求常见问题

01

适合哪些使用情境？

适合希望把时间、日常信息、快捷操作与游戏监测放在副屏幕的用户。也可以利用另一台 Windows 或 Linux 电脑作为连接设备，查看 Windows 主电脑的数据并运行支持的操作。

02

功能介绍

Secondary 由首页、快捷导航与游戏模式三个主要页面组成，可从底部导航切换。以下依功能分区介绍。

首页快捷导航性能监控特色功能

01

首页

自由摆放组件，把副屏幕排成自己习惯的样子。

  • 多种日常组件

    从“＋ 组件”加入时钟、日历、便笺、待办、计数器、时间进度、倒数计时、码表、媒体、天气及倒数日。最多可额外加入 12 个组件，同类型可重复加入。

  • 自由排列与对齐

    拖动标题移位，从四边或四角缩放；接近边线或中心线时会吸附对齐，按住 Alt 可暂时略过。支持键盘调整尺寸，Esc 取消本次拖曳，也能从“选取现有组件”找回被遮住的组件。

  • 媒体与天气

    媒体组件显示目前播放的封面与进度，可切换上一首、播放／暂停与下一首；播放器需支持系统媒体控制。天气依你输入的城市向 Open-Meteo 查询，约每 15 分钟更新。

  • 自订首页外观

    时钟提供数字、翻页、指针三种样式，背景可使用本机图片或循环静音视频。背景只参照本机文件，不拷贝或上传；视频无法播放时会说明原因并改用静态背景。

02

快捷导航

把常用的程序、文件、文件夹与网站分组整理，一键打开。

  • 以分组整理捷径

    添加程序、文件、文件夹与网站，以分组菜单筛选，支持拖入、排序及跨组移动，可选纵向或横向排列。Windows 支持 .lnk 捷径；Linux 提供 .desktop 启动器。

  • 导出与导入设置

    v1.2.0 添加把捷径、分组与排列方式导出成一个文件，换设备或重装后再导入。导入会取代目前设置，取代前自动备份；另一个系统无法运行的捷径会列为“待处理”，可移到主电脑、编辑或删除。

  • 在本机与主电脑之间移动

    v1.2.0 添加连接到主电脑时，编辑捷径可选择存放在“本机”或“主电脑”，捷径会移到所选位置。导入或移动过的捷径，第一次运行时都需要重新确认。

  • 可确认的多步操作

    以打开、等待与外部脚本编排操作；Windows 另有指定窗口快捷键步骤。首次运行或内容变更会要求确认，运行可取消且失败即停；脚本不提权，取消也不会撤销已完成的动作。

03

性能监控

进入游戏模式，实时掌握电脑与游戏的运作状态。

  • 实时游戏监测

    以仪表与 60 秒曲线呈现 CPU、内存、GPU 引擎使用率与网络。手动选择游戏进程后，可取得 FPS、1% Low 与帧间隔。可用底部入口、Ctrl+Alt+G 或系统托盘进出游戏模式。

  • 高低采样切换

    低采样每 3 秒更新基本数据、每 10 秒更新 GPU 与硬件；高采样则为 1 秒与 2 秒，切换立即生效。进入设置、隐藏、最小化、锁定或睡眠时会停止采样。

  • 硬件传感数据

    可手动启用独立硬件助手，取得支持的温度、时脉、功耗与显存；多 GPU 可选择传感设备。Windows 版不会自动提权或安装驱动，可读取的项目依硬件与权限而定。

  • 依实际来源呈现

    各来源分别标示有效、等待、过期或失败；无权限或无数据时显示“—”，不使用示意数值。窗口较小时改为紧凑摘要，首屏保留 FPS、CPU、GPU 等重点读数。

04

特色功能

不同平台、不同设备，都能用自己的方式使用 Secondary。

  • Windows 与 Linux 版本

    提供 Windows 11 x64 与 Ubuntu／GNOME Linux x86_64 版本。Linux 可选 .deb 安装包或免安装 AppImage，各发行包均包含所需的 .NET 运行环境。

  • 连接模式

    没有副屏时，可用另一台 Windows 或 Linux 设备连接主电脑的“连接助手”，输入 6 位数配对码完成配对。连接后可查看主电脑的游戏监测、同步进出游戏模式、控制媒体播放及运行已确认的捷径。只在同一局域网使用，并以 TLS 1.3 加密。

  • 自订导航栏

    导航栏可选标准或小尺寸，并放在画面上、下、左、右任一侧；左右两侧使用直向排列。设置立即套用并保存，日常与游戏模式共用。

  • 节省资源与减少动态

    离开首页、隐藏、最小化或锁定时，停止计时更新、关闭视频并释放背景资源。打开系统“减少动画”时改用静态效果，也会遵循高对比设置。

03

如何开始

  1. 选择平台并下载

    从 GitHub Releases 下载适合平台的发行包。Windows 解压 ZIP 后运行 Secondary.App.exe；Ubuntu／GNOME 可安装 .deb 或打开 AppImage，均不需另装 .NET 运行环境。

  2. 选择副屏或连接模式

    直接使用本机副屏幕时，不需要连接助手。只有要让另一台设备连接主电脑时，才在 Windows 11 x64 主电脑下载连接助手 ZIP，解压并运行 Secondary.Connect.exe。

  3. 设置显示器或完成配对

    本机使用可在设置选择显示器与全屏。连接模式则让两台电脑位于同一局域网，在主机助手按“开始配对”，于设备端搜索主机并输入 6 位数配对码。

  4. 配置组件与游戏监测

    从“＋ 组件”安排首页，以分组整理快捷入口，再进入游戏模式选择进程与采样设置。Linux 的本机游戏 FPS 需另行设置 MangoHud；连接模式使用主电脑的监测来源。

04

系统需求

操作系统
Windows 11 x64，或 Ubuntu／GNOME（Wayland）Linux x86_64。
运行环境
Windows、Linux 与连接助手发行包均已包含所需的 .NET 运行环境。
连接模式
主电脑须为 Windows 11 x64 并运行 Secondary.Connect.exe；连接设备可用 Windows 或 Linux。两端须在同一局域网，配对后以 TLS 1.3 加密连接。
Windows 监测
PresentMon 帧率需要足够的 ETW 权限；CPU 底层温度、功率与频率需要支持的硬件、PawnIO 及设备访问权限。程序不自动提权或安装驱动。
Linux 本机 FPS
需自行安装 MangoHud，并在游戏启动选项加入 Secondary 提供的设置。连接 Windows 主电脑时则使用主机的 PresentMon，不需为此另外设置设备端 MangoHud。

05

常见问题

连接模式可以镜像主电脑画面吗？

不会发送主电脑画面或串流游戏画面。支持的操作是游戏监测、同步进出游戏模式、主机媒体控制与已确认的主机捷径；连接设备保留自己的首页与本机功能。仅供同一局域网使用。

从设备运行主电脑捷径，需要确认吗？

每个主机捷径首次运行，或步骤内容变更后，都需在主电脑画面确认。设备端只能等待确认，游戏模式中不会运行这些捷径。

FPS 或硬件数据显示“—”代表什么？

代表该来源没有可用数据或权限。Windows FPS 受 ETW 权限限制，成功实机采集仍待有足够权限的环境验证；只安装 PawnIO 也不保证能读取所有传感值。Linux 本机 FPS 需可用的 MangoHud 记录，程序不以示意数值代替缺失数据。

导入快捷导航设置会覆盖现有捷径吗？

会。导入会取代目前的捷径、分组与排列方式，取代前会自动备份。从另一个系统导入、这台设备无法运行的捷径会列为“待处理”，不会在这台设备上运行；导入的捷径第一次运行时需重新确认。

Windows 更新后会保留原本设置吗？

会沿用既有设置与布局。更新前先从系统托盘完全退出旧程序，将新版 ZIP 解压到新目录，再启动其中的 Secondary.App.exe。连接助手只在使用连接模式时需要。

Linux 版本的验收进度如何？

自 v1.1.0 起提供 Ubuntu／GNOME 发行包，包含首页、快捷导航与游戏模式。长时间运作、无障碍与实体副屏验收仍在进行；实际监测数据依设备、驱动与权限而定。

关闭 Windows 窗口后，程序会结束吗？

关闭窗口会隐藏到系统托盘。使用系统托盘的“退出 Secondary”才会结束程序。

自订背景会上传到云端吗？

不会。背景只参照你选择的本机文件，不拷贝或上传。文件遗失或视频无法解码时会显示原因并回退静态背景，程序不会自动安装编解码器。
