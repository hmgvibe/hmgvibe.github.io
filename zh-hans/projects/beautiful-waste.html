Beautiful Waste

让闲置屏幕，只留下时间、光与留白。

氛围时钟 · Windows

Beautiful Waste 是 Windows 原生氛围时钟。持续流动的柔和光雾配上时间、日期与短句，适合放在副屏幕或以全屏显示，营造安静的桌面背景。

01

适合哪些使用情境？

适合想让闲置屏幕更有氛围、喜欢简洁时钟，或希望用自订短句和柔和动态背景陪伴工作的人。

02

功能特色

  • 动态柔和光雾

    以 WGPU 着色器绘制流动的背景，调整动画速度以符合喜欢的节奏。

  • 多种时间样式

    五种时钟字体、12/24 小时制与多种日期格式，调整中央时钟大小及秒数显示。

  • 轮换短句

    切换内置短句、设置显示间隔，以及顺序或随机播放。

  • 自订语句库

    添加与删除自己的句子，也能从 TXT 导入每一个非空白行。

  • 全屏与媒体控制

    进入全屏显示，以 Esc 退出；支持 Windows 上一首、播放／暂停与下一首媒体操作。

  • 偏好本机保存

    启动时恢复外观与短句设置，不需要账号或网络连接。

03

如何开始

  1. 下载并打开

    从 GitHub Releases 下载 Windows x64 ZIP，解压后运行 beautiful-waste.exe。

  2. 调整时钟与背景

    打开左侧设置菜单，切换字体、时间格式、中央时钟大小与动画速度。

  3. 加入自己的语句

    在 CUSTOM TEXT 输入句子并选择 ADD PHRASE，或用 IMPORT TXT 导入文字档。

  4. 选择显示方式

    设置轮换间隔与播放顺序，依需要使用右上角全屏入口；Esc 可退出全屏。

05

常见问题

关闭后会记住自订短句吗？

会。设置与语句保存在本机，重新启动会恢复偏好。

TXT 要用什么格式？

IMPORT TXT 会把每一个非空白行导入为一句话；适合先将语句整理成每行一则。

重设会影响哪些内容？

设置底部的 DELETE USER FILES 需要连续确认两次，会删除本机设置与自订语句档，并恢复默认设置和内置短句。
