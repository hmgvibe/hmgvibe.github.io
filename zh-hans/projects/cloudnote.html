CloudNotes

随时记下想法，离线编辑，回到云端同步。

CloudNotes 是 Nextcloud Notes 的 Android 笔记工具。提供 Markdown 编辑与预览、分类、搜索和收藏；笔记下载后可离线使用，并可为个别笔记加密内容。

01OVERVIEW

适合哪些使用情境？

适合用 Nextcloud 保存笔记，希望在手机上随时编辑，并为私人内容设置密码或指纹解锁的用户。

02FEATURES

功能特色

  • 完整笔记操作

    创建、编辑、删除、搜索、分类与收藏笔记，让日常内容集中管理。

  • Markdown 编辑

    提供 Markdown 编辑工具与阅读预览，方便整理段落和结构。

  • 离线编辑

    同步下载后的笔记可在没有网络时阅读及修改，支持手动与背景同步。

  • 个别内容加密

    以至少 8 字符密码保护特定笔记，内容与原始分类加密，标题仍可搜索。

  • 指纹解锁

    先以笔记密码解锁，再启用设备上的生物识别功能。

  • 语言与外观

    支持英文、繁体中文、简体中文，以及浅色、深色与跟随系统主题。

03GETTING STARTED

如何开始

  1. 准备 Nextcloud Notes

    在 HTTPS Nextcloud 启用 Notes，确认服务支持 Notes API 1.2 或以上。

  2. 安装并登录

    安装 GitHub Releases 的 APK，输入 Nextcloud 根网址，通过浏览器授权或 App 密码登录。

  3. 完成首次同步

    等待云端笔记下载，之后即可离线阅读及编辑，并使用分类、搜索与收藏整理内容。

  4. 按需要加密笔记

    在首页创建加密笔记，或在编辑器加密既有内容。先用密码解锁，再选择启用指纹。

04REQUIREMENTS

系统需求

Android
Android 8.0 或以上。
服务器
HTTPS Nextcloud，启用 Notes，支持 Notes API 1.2 或以上。
登录网址
输入 Nextcloud 根网址，而不是 Notes 网页地址。

05GOOD TO KNOW

常见问题

加密笔记的标题也会隐藏吗？

不会。标题与必要元数据仍会公开及同步，内容和原始分类才被加密。加密内容无法搜索，也无法在 Nextcloud Notes 网页端解密。

两端同时修改一篇笔记会怎么处理？

修改时间较新的内容优先；同一秒的修改由云端优先，不创建另一份冲突副本。云端删除也会移除本机笔记，请保持设备时间准确。

忘记加密密码后可以复原吗？

若忘记密码且没有可用的指纹密钥，内容无法复原。加密既有笔记也不会清除云端历史版本或备份里的旧明文。
