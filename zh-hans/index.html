学习管理Android · Nextcloud

ClassFlow

课表、作业与考试，一起安排。

管理固定课表、作业、考试与学习计划。同步版可连接 Nextcloud 网页端，独立离线版则不需账号或服务器。

02 / 09CONCEPT VISUAL↗
输入工具 · NEWWindows

TouchWrite

让触摸板，变成你的手写板。

在 Windows 重现 Mac 的触摸板手写。按下快捷键，用手指在触摸板上写字，识别出的字直接输入到目前的输入框，支持候选字、两指手势与繁简输出。

探索项目↗
03 / 09CONCEPT VISUAL↗
专注工具Android

Phnomy

留一段时间，只做眼前这件事。

完全离线的专注计时工具，提供番茄钟、App 白名单与本机统计。用 60 秒冷静等待减少冲动退出，不需账号，也不收集追踪数据。

04 / 09CONCEPT VISUAL↗
桌面工具Windows · Linux

Secondary

让第二个屏幕，成为你的控制中心。

Windows 与 Linux 桌面工具，集成可自由编排的组件、快捷导航与游戏监测。通过局域网连接，也能用另一台设备查看 Windows 主电脑信息、控制媒体与运行已确认的捷径。

探索项目↗
05 / 09CONCEPT VISUAL↗
文件传输Android · Windows

QRTrans

让数据通过光，抵达另一台设备。

将文件或文字转为连续变化的 QR Code，再用另一台设备的相机接收。整个传输过程不需要网络、账号或云端服务。

06 / 09CONCEPT VISUAL↗
照片管理Android · Nextcloud

NextPhoto

自己的照片，放在自己的云端。

为 Nextcloud 相片打造的 Android 图库。用日期分组浏览照片与视频，管理云端相册、备份手机照片，也能保存离线副本。

探索项目↗
07 / 09CONCEPT VISUAL↗
笔记工具Android · Nextcloud

CloudNotes

离线记下想法，回到云端同步。

连接自己的 Nextcloud Notes，在手机上创建、整理与编辑笔记。提供 Markdown 编辑与预览，并能为个别笔记加上密码保护。

探索项目↗
08 / 09CONCEPT VISUAL↗
游戏工具Android · Windows

MPad

把手机，变成你的游戏手柄。

用 Android 手机触摸控制 Windows 游戏。通过局域网或蓝牙连接电脑伴侣程序，将输入转换成 Xbox 360 / XInput 手柄信号。

氛围时钟Windows

Beautiful Waste

时间、光，还有一点留白。

一个专注于视觉氛围的 Windows 桌面时钟。柔和光雾持续流动，搭配时间、日期与轮换短句，适合放在闲置屏幕上。
