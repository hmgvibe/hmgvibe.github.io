Secondary

把第二個螢幕變成自己的桌面控制中心。

Secondary v1.2.0 是 Windows 11 與 Ubuntu／GNOME Linux 的副屏應用程式，整合可編輯的首頁組件、分組快捷導航與遊戲監測。沒有副屏時，也能在另一台 Windows 或 Linux 設備執行 Secondary，透過區域網路連接主電腦的「連接助手」，查看監測資料、控制媒體與執行已確認的捷徑。

01OVERVIEW

適合哪些使用情境？

適合希望把時間、日常資訊、快捷操作與遊戲監測放在副螢幕的使用者。也可以利用另一台 Windows 或 Linux 電腦作為連線設備，查看 Windows 主電腦的資料並執行支援的操作。

02FEATURES

功能介紹

Secondary 由首頁、快捷導航與遊戲模式三個主要頁面組成，可從底部導航切換。以下依功能分區介紹。

首頁快捷導航性能監控特色功能

01 — HOME

首頁

自由擺放組件，把副螢幕排成自己習慣的樣子。

  • 多種日常組件

    從「＋ 組件」加入時鐘、日曆、便箋、待辦、計數器、時間進度、倒數計時、碼錶、媒體、天氣及倒數日。最多可額外加入 12 個組件，同類型可重複加入。

  • 自由排列與對齊

    拖動標題移位，從四邊或四角縮放；接近邊線或中心線時會吸附對齊，按住 Alt 可暫時略過。支援鍵盤調整尺寸，Esc 取消本次拖曳，也能從「選取現有組件」找回被遮住的組件。

  • 媒體與天氣

    媒體組件顯示目前播放的封面與進度，可切換上一首、播放／暫停與下一首；播放器需支援系統媒體控制。天氣依你輸入的城市向 Open-Meteo 查詢，約每 15 分鐘更新。

  • 自訂首頁外觀

    時鐘提供數字、翻頁、指針三種樣式，背景可使用本機圖片或循環靜音影片。背景只參照本機檔案，不複製或上傳；影片無法播放時會說明原因並改用靜態背景。

02 — SHORTCUTS

快捷導航

把常用的程式、檔案、資料夾與網站分組整理，一鍵開啟。

  • 以分組整理捷徑

    新增程式、檔案、資料夾與網站，以分組選單篩選，支援拖入、排序及跨組移動，可選縱向或橫向排列。Windows 支援 .lnk 捷徑；Linux 提供 .desktop 啟動器。

  • 匯出與匯入設定

    v1.2.0 新增把捷徑、分組與排列方式匯出成一個檔案，換設備或重裝後再匯入。匯入會取代目前設定，取代前自動備份；另一個系統無法執行的捷徑會列為「待處理」，可移到主電腦、編輯或刪除。

  • 在本機與主電腦之間移動

    v1.2.0 新增連線到主電腦時，編輯捷徑可選擇存放在「本機」或「主電腦」，捷徑會移到所選位置。匯入或移動過的捷徑，第一次執行時都需要重新確認。

  • 可確認的多步操作

    以開啟、等待與外部腳本編排操作；Windows 另有指定視窗快捷鍵步驟。首次執行或內容變更會要求確認，執行可取消且失敗即停；腳本不提權，取消也不會撤銷已完成的動作。

03 — PERFORMANCE

性能監控

進入遊戲模式，即時掌握電腦與遊戲的運作狀態。

  • 即時遊戲監測

    以儀錶與 60 秒曲線呈現 CPU、記憶體、GPU 引擎使用率與網路。手動選擇遊戲程序後，可取得 FPS、1% Low 與幀間隔。可用底部入口、Ctrl+Alt+G 或系統匣進出遊戲模式。

  • 高低採樣切換

    低採樣每 3 秒更新基本資料、每 10 秒更新 GPU 與硬體；高採樣則為 1 秒與 2 秒，切換立即生效。進入設定、隱藏、最小化、鎖定或睡眠時會停止採樣。

  • 硬體感測資料

    可手動啟用獨立硬體助手，取得支援的溫度、時脈、功耗與顯存；多 GPU 可選擇感測裝置。Windows 版不會自動提權或安裝驅動，可讀取的項目依硬體與權限而定。

  • 依實際來源呈現

    各來源分別標示有效、等待、過期或失敗；無權限或無資料時顯示「—」，不使用示意數值。視窗較小時改為緊湊摘要，首屏保留 FPS、CPU、GPU 等重點讀數。

04 — HIGHLIGHTS

特色功能

不同平台、不同設備，都能用自己的方式使用 Secondary。

  • Windows 與 Linux 版本

    提供 Windows 11 x64 與 Ubuntu／GNOME Linux x86_64 版本。Linux 可選 .deb 安裝包或免安裝 AppImage，各發行包均包含所需的 .NET 執行環境。

  • 連線模式

    沒有副屏時，可用另一台 Windows 或 Linux 設備連接主電腦的「連接助手」，輸入 6 位數配對碼完成配對。連線後可查看主電腦的遊戲監測、同步進出遊戲模式、控制媒體播放及執行已確認的捷徑。只在同一區域網路使用，並以 TLS 1.3 加密。

  • 自訂導航欄

    導航欄可選標準或小尺寸，並放在畫面上、下、左、右任一側；左右兩側使用直向排列。設定立即套用並保存，日常與遊戲模式共用。

  • 節省資源與減少動態

    離開首頁、隱藏、最小化或鎖定時，停止計時更新、關閉影片並釋放背景資源。開啟系統「減少動畫」時改用靜態效果，也會遵循高對比設定。

03GETTING STARTED

如何開始

  1. 選擇平台並下載

    從 GitHub Releases 下載適合平台的發行包。Windows 解壓 ZIP 後執行 Secondary.App.exe；Ubuntu／GNOME 可安裝 .deb 或開啟 AppImage，均不需另裝 .NET 執行環境。

  2. 選擇副屏或連線模式

    直接使用本機副螢幕時，不需要連接助手。只有要讓另一台設備連接主電腦時，才在 Windows 11 x64 主電腦下載連接助手 ZIP，解壓並執行 Secondary.Connect.exe。

  3. 設定顯示器或完成配對

    本機使用可在設定選擇顯示器與全螢幕。連線模式則讓兩台電腦位於同一區域網路，在主機助手按「開始配對」，於設備端搜尋主機並輸入 6 位數配對碼。

  4. 配置組件與遊戲監測

    從「＋ 組件」安排首頁，以分組整理快捷入口，再進入遊戲模式選擇程序與採樣設定。Linux 的本機遊戲 FPS 需另行設定 MangoHud；連線模式使用主電腦的監測來源。

04REQUIREMENTS

系統需求

作業系統
Windows 11 x64，或 Ubuntu／GNOME（Wayland）Linux x86_64。
執行環境
Windows、Linux 與連接助手發行包均已包含所需的 .NET 執行環境。
連線模式
主電腦須為 Windows 11 x64 並執行 Secondary.Connect.exe；連線設備可用 Windows 或 Linux。兩端須在同一區域網路，配對後以 TLS 1.3 加密連線。
Windows 監測
PresentMon 幀率需要足夠的 ETW 權限；CPU 底層溫度、功率與頻率需要支援的硬體、PawnIO 及裝置存取權限。程式不自動提權或安裝驅動。
Linux 本機 FPS
需自行安裝 MangoHud，並在遊戲啟動選項加入 Secondary 提供的設定。連接 Windows 主電腦時則使用主機的 PresentMon，不需為此另外設定設備端 MangoHud。

05GOOD TO KNOW

常見問題

連線模式可以鏡像主電腦畫面嗎？

不會傳送主電腦畫面或串流遊戲畫面。支援的操作是遊戲監測、同步進出遊戲模式、主機媒體控制與已確認的主機捷徑；連線設備保留自己的首頁與本機功能。僅供同一區域網路使用。

從設備執行主電腦捷徑，需要確認嗎？

每個主機捷徑首次執行，或步驟內容變更後，都需在主電腦畫面確認。設備端只能等待確認，遊戲模式中不會執行這些捷徑。

FPS 或硬體資料顯示「—」代表什麼？

代表該來源沒有可用資料或權限。Windows FPS 受 ETW 權限限制，成功實機採集仍待有足夠權限的環境驗證；只安裝 PawnIO 也不保證能讀取所有感測值。Linux 本機 FPS 需可用的 MangoHud 記錄，程式不以示意數值代替缺失資料。

匯入快捷導航設定會覆蓋現有捷徑嗎？

會。匯入會取代目前的捷徑、分組與排列方式，取代前會自動備份。從另一個系統匯入、這台設備無法執行的捷徑會列為「待處理」，不會在這台設備上執行；匯入的捷徑第一次執行時需重新確認。

Windows 更新後會保留原本設定嗎？

會沿用既有設定與布局。更新前先從系統匣完全退出舊程式，將新版 ZIP 解壓到新目錄，再啟動其中的 Secondary.App.exe。連接助手只在使用連線模式時需要。

Linux 版本的驗收進度如何？

自 v1.1.0 起提供 Ubuntu／GNOME 發行包，包含首頁、快捷導航與遊戲模式。長時間運作、無障礙與實體副屏驗收仍在進行；實際監測資料依裝置、驅動與權限而定。

關閉 Windows 視窗後，程式會結束嗎？

關閉視窗會隱藏到系統匣。使用系統匣的「退出 Secondary」才會結束程式。

自訂背景會上傳到雲端嗎？

不會。背景只參照你選擇的本機檔案，不複製或上傳。檔案遺失或影片無法解碼時會顯示原因並回退靜態背景，程式不會自動安裝編解碼器。
