Secondary

把第二個螢幕變成自己的桌面控制中心。

Secondary v1.1.0 是 Windows 11 與 Ubuntu／GNOME Linux 的副屏應用程式，整合可編輯的首頁組件、分組快捷導航與遊戲監測。沒有副屏時，也能在另一台 Windows 或 Linux 設備執行 Secondary，透過區域網路連接主電腦的「連接助手」，查看監測資料、控制媒體與執行已確認的捷徑。

01OVERVIEW

適合哪些使用情境？

適合希望把時間、日常資訊、快捷操作與遊戲監測放在副螢幕的使用者。也可以利用另一台 Windows 或 Linux 電腦作為連線設備，查看 Windows 主電腦的資料並執行支援的操作。

02FEATURES

功能特色

  • Windows 與 Linux 版本

    提供 Windows 11 x64 與 Ubuntu／GNOME Linux x86_64 版本。Linux 可選 .deb 安裝包或免安裝 AppImage，各發行包均包含所需的 .NET 執行環境。

  • 區域網路連線與配對

    Windows 主電腦啟動連接助手，另一台 Windows 或 Linux 設備搜尋並輸入 6 位數配對碼。只在同一區域網路使用，後續以 TLS 1.3 加密並只接受已配對設備。

  • 在另一台設備操作主電腦

    查看主電腦的遊戲監測，選擇主機程序並同步進出遊戲模式；媒體組件可控制主機播放，快捷導航也能加入並執行存放在主電腦的捷徑。

  • 自由排列與對齊組件

    拖動組件，從四邊或四角縮放；接近邊線或中心線時會吸附對齊，Alt 可暫時略過。支援鍵盤調整、Esc 取消本次拖曳，也能從「選取現有組件」找回被遮住的內容。

  • 日常資訊與首頁外觀

    加入時鐘、日曆、便箋、待辦、計數器、計時工具、媒體、天氣及倒數日。提供三種時鐘樣式與本機圖片、影片背景；播放器與影片解碼能力依平台環境而定。

  • 以分組整理快捷導航

    以分組選單篩選程式、檔案、資料夾與網站，支援拖入、排序及跨組移動，可選縱向或橫向排列。Windows 支援 .lnk；Linux 提供 .desktop 啟動器。

  • 可確認的多步操作

    以開啟、等待與外部腳本編排操作；Windows 另有指定視窗快捷鍵步驟。首次執行或內容變更會要求確認，執行可取消且失敗即停；取消不會撤銷已完成的動作。

  • 依實際來源呈現遊戲監測

    呈現 CPU、記憶體、GPU、網路、幀率與歷史曲線，可選程序及高低採樣。來源分別標示有效、等待、過期或失敗；無權限或無資料顯示「—」，不使用示意數值。

03GETTING STARTED

如何開始

  1. 選擇平台並下載

    從 GitHub Releases 下載適合平台的發行包。Windows 解壓 ZIP 後執行 Secondary.App.exe；Ubuntu／GNOME 可安裝 .deb 或開啟 AppImage，均不需另裝 .NET 執行環境。

  2. 選擇副屏或連線模式

    直接使用本機副螢幕時，不需要連接助手。只有要讓另一台設備連接主電腦時，才在 Windows 11 x64 主電腦下載連接助手 ZIP，解壓並執行 Secondary.Connect.exe。

  3. 設定顯示器或完成配對

    本機使用可在設定選擇顯示器與全螢幕。連線模式則讓兩台電腦位於同一區域網路，在主機助手按「開始配對」，於設備端搜尋主機並輸入 6 位數配對碼。

  4. 配置組件與遊戲監測

    從「＋ 組件」安排首頁，以分組整理快捷入口，再進入遊戲模式選擇程序與採樣設定。Linux 的本機遊戲 FPS 需另行設定 MangoHud；連線模式使用主電腦的監測來源。

04REQUIREMENTS

系統需求

作業系統
Windows 11 x64，或 Ubuntu／GNOME（Wayland）Linux x86_64。
執行環境
Windows、Linux 與連接助手發行包均已包含所需的 .NET 執行環境。
連線模式
主電腦須為 Windows 11 x64 並執行 Secondary.Connect.exe；連線設備可用 Windows 或 Linux。兩端須在同一區域網路，配對後以 TLS 1.3 加密連線。
Windows 監測
PresentMon 幀率需要足夠的 ETW 權限；CPU 底層溫度、功率與頻率需要支援的硬體、PawnIO 及裝置存取權限。程式不自動提權或安裝驅動。
Linux 本機 FPS
需自行安裝 MangoHud，並在遊戲啟動選項加入 Secondary 提供的設定。連接 Windows 主電腦時則使用主機的 PresentMon，不需為此另外設定設備端 MangoHud。

05GOOD TO KNOW

常見問題

連線模式可以鏡像主電腦畫面嗎？

不會傳送主電腦畫面或串流遊戲畫面。支援的操作是遊戲監測、同步進出遊戲模式、主機媒體控制與已確認的主機捷徑；連線設備保留自己的首頁與本機功能。僅供同一區域網路使用。

從設備執行主電腦捷徑，需要確認嗎？

每個主機捷徑首次執行，或步驟內容變更後，都需在主電腦畫面確認。設備端只能等待確認，遊戲模式中不會執行這些捷徑。

FPS 或硬體資料顯示「—」代表什麼？

代表該來源沒有可用資料或權限。Windows FPS 受 ETW 權限限制，成功實機採集仍待有足夠權限的環境驗證；只安裝 PawnIO 也不保證能讀取所有感測值。Linux 本機 FPS 需可用的 MangoHud 記錄，程式不以示意數值代替缺失資料。

Windows 更新後會保留原本設定嗎？

會沿用既有設定與布局。更新前先從系統匣完全退出舊程式，將新版 ZIP 解壓到新目錄，再啟動其中的 Secondary.App.exe。連接助手只在使用連線模式時需要。

Linux 版本的驗收進度如何？

v1.1.0 已提供 Ubuntu／GNOME 發行包，包含首頁、快捷導航與遊戲模式。長時間運作、無障礙與實體副屏驗收仍在進行；實際監測資料依裝置、驅動與權限而定。

關閉 Windows 視窗後，程式會結束嗎？

關閉視窗會隱藏到系統匣。使用系統匣的「退出 Secondary」才會結束程式。

自訂背景會上傳到雲端嗎？

不會。背景只參照你選擇的本機檔案，不複製或上傳。檔案遺失或影片無法解碼時會顯示原因並回退靜態背景，程式不會自動安裝編解碼器。
