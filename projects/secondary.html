Secondary

把第二個螢幕變成自己的桌面控制中心。

⊞

Secondary 是 Windows 副屏應用程式，整合自由排列的首頁組件、快捷導航與遊戲監測。你可以依照螢幕與使用習慣安排資訊，在日常工具與遊戲模式間切換。

OVERVIEW

適合哪些使用情境？

適合有第二個螢幕、希望隨時查看時間與系統狀態，或需要集中管理常用程式和快捷操作的 Windows 使用者。

FEATURES

功能特色

  • 自由排列組件

    加入時鐘、日曆、便箋、待辦、計數器與計時工具；拖動位置、獨立調整寬高，設定會保存到本機。

  • 自訂首頁外觀

    使用本機圖片、影片或內建背景，搭配數字、翻頁或指針時鐘，調整成符合副螢幕的畫面。

  • 快捷導航

    整理程式、檔案、資料夾、網站與捷徑，支援分組、搜尋、拖入與拖曳排序。

  • 多步快捷操作

    編排開啟、等待、視窗快捷鍵與外部腳本等步驟；執行可取消，發生錯誤即停止。

  • 遊戲監測

    以儀表呈現 CPU、記憶體、GPU、網路與歷史曲線；支援選擇程序與調整採樣頻率。

  • 桌面資訊

    加入媒體控制、天氣與倒數日組件，管理導航欄位置、主題、快捷鍵與顯示器。

GETTING STARTED

如何開始

  1. 下載並解壓縮

    從 GitHub Releases 下載 Windows x64 ZIP，解壓後執行 Secondary.App.exe；發行包包含所需的 .NET 執行環境。

  2. 設定顯示器

    在設定頁選擇副螢幕及全螢幕顯示，依習慣調整導航欄位置與尺寸。

  3. 安排首頁與快捷入口

    從「＋ 組件」加入資訊，拖動和縮放；在快捷導航建立常用的程式、資料夾或網站入口。

  4. 使用遊戲模式

    透過導航入口、Ctrl+Alt+G 或系統匣進入，選擇要監測的程序與採樣設定。

GOOD TO KNOW

常見問題

FPS 顯示「—」代表什麼？

代表目前沒有可用資料或存取權限。PresentMon 幀率採集受 ETW 權限限制，程式不會用示意數值代替未取得的資料。

關閉視窗後，程式會結束嗎？

關閉視窗會隱藏到系統匣。使用系統匣的「退出 Secondary」才會結束程式。

自訂背景會上傳到雲端嗎？

不會。背景只參照你選擇的本機檔案；檔案遺失或影片無法解碼時，會顯示原因並回退靜態背景。
