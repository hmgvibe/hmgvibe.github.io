Beautiful Waste

讓閒置螢幕，只留下時間、光與留白。

氛圍時鐘 · Windows

Beautiful Waste 是 Windows 原生氛圍時鐘。持續流動的柔和光霧配上時間、日期與短句，適合放在副螢幕或以全螢幕顯示，營造安靜的桌面背景。

01

適合哪些使用情境？

適合想讓閒置螢幕更有氛圍、喜歡簡潔時鐘，或希望用自訂短句和柔和動態背景陪伴工作的人。

02

功能特色

  • 動態柔和光霧

    以 WGPU 著色器繪製流動的背景，調整動畫速度以符合喜歡的節奏。

  • 多種時間樣式

    五種時鐘字體、12/24 小時制與多種日期格式，調整中央時鐘大小及秒數顯示。

  • 輪換短句

    切換內建短句、設定顯示間隔，以及順序或隨機播放。

  • 自訂語句庫

    新增與刪除自己的句子，也能從 TXT 匯入每一個非空白行。

  • 全螢幕與媒體控制

    進入全螢幕顯示，以 Esc 退出；支援 Windows 上一首、播放／暫停與下一首媒體操作。

  • 偏好本機保存

    啟動時恢復外觀與短句設定，不需要帳號或網路連線。

03

如何開始

  1. 下載並開啟

    從 GitHub Releases 下載 Windows x64 ZIP，解壓後執行 beautiful-waste.exe。

  2. 調整時鐘與背景

    開啟左側設定選單，切換字體、時間格式、中央時鐘大小與動畫速度。

  3. 加入自己的語句

    在 CUSTOM TEXT 輸入句子並選擇 ADD PHRASE，或用 IMPORT TXT 匯入文字檔。

  4. 選擇顯示方式

    設定輪換間隔與播放順序，依需要使用右上角全螢幕入口；Esc 可退出全螢幕。

04

系統需求

作業系統
Windows 10/11。
圖形環境
可用的 DirectX 12 或 Vulkan 圖形驅動。
其他條件
不需帳號、網路或額外的 Electron / WebView 執行環境。

05

常見問題

關閉後會記住自訂短句嗎？

會。設定與語句保存在本機，重新啟動會恢復偏好。

TXT 要用什麼格式？

IMPORT TXT 會把每一個非空白行匯入為一句話；適合先將語句整理成每行一則。

重設會影響哪些內容？

設定底部的 DELETE USER FILES 需要連續確認兩次，會刪除本機設定與自訂語句檔，並恢復預設設定和內建短句。
