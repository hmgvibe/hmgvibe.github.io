QRTrans

用 QR Code 和相機，在沒有網路時傳送資料。

檔案傳輸 · Android · Windows

QRTrans 將單一檔案或文字轉為持續變化的 QR Code，接收裝置用相機掃描畫面，還原並驗證內容。傳輸透過螢幕與相機完成，不需要網路路徑、帳號、配對或雲端服務。

01

適合哪些使用情境？

適合裝置無法建立網路連線、希望避免雲端中轉，或需要透過螢幕向 Android 裝置傳送檔案的情境。

02

功能特色

  • 檔案與文字

    可傳送最大 64 MB 的單一檔案，或 UTF-8 文字內容。

  • Android 與 Windows

    Android 支援傳送與接收；Windows 支援傳送，可將資料送到 Android。

  • 從中途開始掃描

    QR Code 持續輪播，接收端不需要等候傳送端重新開始。

  • 修復缺失資料

    噴泉碼搭配修復幀，容忍丟幀、重複幀與亂序幀。

  • 可調顯示方式

    同時顯示 1、2 或 4 個 QR Code，並調整 10–60 FPS 的顯示頻率。

  • 可選密碼保護

    以 Argon2id 與 XChaCha20-Poly1305 保護傳輸內容；使用 SHA-256 檢查資料完整性。

03

如何開始

  1. 安裝適合平台的版本

    從 GitHub Releases 下載 Android 或 Windows 版本，準備一台可傳送的裝置和一台 Android 接收裝置。

  2. 選擇要傳送的內容

    在傳送端選擇單一檔案或輸入文字；需要保護內容時啟用密碼。

  3. 顯示並掃描 QR Code

    讓傳送端開始輪播，接收端開啟相機對準畫面。可依掃描情況調整 QR Code 數量與顯示頻率。

  4. 等待還原與驗證

    持續掃描直到資料完整，依接收流程完成解密並取得內容。

04

系統需求

Android
Android 7.0 / API 24 或以上，支援傳送與接收。
Windows
Windows 10 build 19041 或以上，x64，僅支援傳送。
接收環境
Android 裝置需可用相機與相機權限，能清楚拍到傳送畫面。

05

常見問題

沒有 Wi-Fi 或藍牙也能使用嗎？

可以。檔案與文字經由 QR Code 畫面傳送，不使用網路連線或藍牙配對。

沒有設定密碼時，旁人能讀取資料嗎？

未加密的 QR Code 可被對準螢幕的相機讀取。敏感內容請啟用密碼保護，加密涵蓋檔名與媒體類型。

可以和 decimen.app 互傳嗎？

不可以。QRTrans 的 Android 與 Windows 版本使用獨立的 QRT1 協議，彼此可互傳，但不相容 decimen.app。
