CloudNotes

隨時記下想法，離線編輯，回到雲端同步。

≡

CloudNotes 是 Nextcloud Notes 的 Android 筆記工具。提供 Markdown 編輯與預覽、分類、搜尋和收藏；筆記下載後可離線使用，並可為個別筆記加密內容。

OVERVIEW

適合哪些使用情境？

適合用 Nextcloud 保存筆記，希望在手機上隨時編輯，並為私人內容設定密碼或指紋解鎖的使用者。

FEATURES

功能特色

  • 完整筆記操作

    建立、編輯、刪除、搜尋、分類與收藏筆記，讓日常內容集中管理。

  • Markdown 編輯

    提供 Markdown 編輯工具與閱讀預覽，方便整理段落和結構。

  • 離線編輯

    同步下載後的筆記可在沒有網路時閱讀及修改，支援手動與背景同步。

  • 個別內容加密

    以至少 8 字元密碼保護特定筆記，內容與原始分類加密，標題仍可搜尋。

  • 指紋解鎖

    先以筆記密碼解鎖，再啟用裝置上的生物辨識功能。

  • 語言與外觀

    支援英文、繁體中文、簡體中文，以及淺色、深色與跟隨系統主題。

GETTING STARTED

如何開始

  1. 準備 Nextcloud Notes

    在 HTTPS Nextcloud 啟用 Notes，確認服務支援 Notes API 1.2 或以上。

  2. 安裝並登入

    安裝 GitHub Releases 的 APK，輸入 Nextcloud 根網址，透過瀏覽器授權或 App 密碼登入。

  3. 完成首次同步

    等待雲端筆記下載，之後即可離線閱讀及編輯，並使用分類、搜尋與收藏整理內容。

  4. 按需要加密筆記

    在首頁建立加密筆記，或在編輯器加密既有內容。先用密碼解鎖，再選擇啟用指紋。

REQUIREMENTS

系統需求

Android
Android 8.0 或以上。
伺服器
HTTPS Nextcloud，啟用 Notes，支援 Notes API 1.2 或以上。
登入網址
輸入 Nextcloud 根網址，而不是 Notes 網頁地址。

GOOD TO KNOW

常見問題

加密筆記的標題也會隱藏嗎？

不會。標題與必要中繼資料仍會公開及同步，內容和原始分類才被加密。加密內容無法搜尋，也無法在 Nextcloud Notes 網頁端解密。

兩端同時修改一篇筆記會怎麼處理？

修改時間較新的內容優先；同一秒的修改由雲端優先，不建立另一份衝突副本。雲端刪除也會移除本機筆記，請保持裝置時間準確。

忘記加密密碼後可以復原嗎？

若忘記密碼且沒有可用的指紋金鑰，內容無法復原。加密既有筆記也不會清除雲端歷史版本或備份裡的舊明文。
