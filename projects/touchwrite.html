TouchWrite

用手指在觸控板上寫字，就能輸入。

輸入工具 · Windows

TouchWrite 在 Windows 上重現 macOS 的觸控板手寫。按下快捷鍵，觸控板就變成手寫板；用一根手指寫字，Windows 內建的手寫辨識會把結果直接輸入到目前的輸入框，不必切換輸入法，也不用另外開視窗。

功能介紹如何開始系統需求常見問題

01

適合哪些使用情境？

適合遇到不會拼音、注音或倉頡的字，想直接寫出來的人；也適合習慣 Mac 觸控板手寫、換到 Windows 筆電後仍想這樣輸入的使用者。手寫面板不搶焦點，寫好的字會直接送到正在使用的程式。

02

功能介紹

  • 觸控板就是手寫板

    按 Ctrl + Shift + Space 開始或停止手寫，也可在設定中錄製任意組合鍵。螢幕上的面板與觸控板位置一一對應：頂部一條是候選字，右上角是刪除鍵，其餘是書寫區。

  • 自動輸入與候選字

    停筆約 0.9 秒後自動輸入第一個候選字，等待時間可調整，也能關閉自動輸入。輕點觸控板頂部或按 1–9 選擇候選字，會替換剛輸入的字。

  • 兩指手勢

    兩指向右滑輸入空格、向下滑換行、向上滑撤銷上一筆，兩指輕點立刻輸入目前的字。輕點右上角刪除，按住可連續刪除；寫字途中則清除筆劃。

  • 寫字時鎖定滑鼠

    手寫模式下滑鼠指標會被鎖定，避免寫字時移動游標或誤點。按 Esc 或快捷鍵退出手寫後，滑鼠立即恢復。

  • 繁體與簡體輸出

    使用 Windows 語言套件內建的手寫辨識，可選擇辨識引擎。輸出字形可保持辨識結果，或一律轉為繁體或簡體後再輸入。

  • 常駐系統匣

    啟動後在系統匣待命，可設定手寫面板大小與登入 Windows 時自動啟動。介面語言可選跟隨系統、繁體中文或简体中文。

03

如何開始

  1. 下載並開啟

    從 GitHub Releases 下載最新版本，執行 TouchWrite.exe。啟動後程式會在系統匣（右下角）待命。

  2. 確認手寫辨識

    右鍵點系統匣圖示開啟設定，在「手寫辨識」確認可用的辨識引擎。想辨識繁體字，可在 Windows 語言設定為中文（台灣）或中文（香港）安裝「手寫」。

  3. 按快捷鍵開始寫字

    點進想輸入文字的地方，按 Ctrl + Shift + Space，用一根手指在觸控板上寫字。停筆後會自動輸入，也可以點選候選字。

  4. 按 Esc 結束

    沒有筆劃時按 Esc，或再按一次快捷鍵，即可退出手寫模式，滑鼠也會立即恢復。

04

系統需求

作業系統
Windows 10（1809）或以上，x64。
執行環境
需要 .NET 9 桌面執行環境。
觸控板
精確式觸控板（Precision Touchpad）。大部分 2018 年後的筆電都支援；舊式 Synaptics／ELAN 驅動的觸控板讀不到手指的絕對位置。
手寫辨識
Windows 手寫辨識語言套件。中文（簡體）辨識器也能辨識不少繁體字；需要繁體辨識時，可另外安裝中文（台灣）或中文（香港）的「手寫」。

05

常見問題

我的觸控板可以使用嗎？

需要精確式觸控板（Precision Touchpad），大部分 2018 年後的筆電都是。舊式 Synaptics 或 ELAN 驅動的觸控板讀不到手指的絕對位置，無法用來手寫。

為什麼手寫時滑鼠不能動？

為了避免寫字時移動游標或誤點，手寫期間所有滑鼠（包括外接滑鼠）都會暫停。按 Esc 或快捷鍵退出手寫，滑鼠就會恢復。

為什麼某些視窗無法輸入文字？

Windows 不允許一般程式向以系統管理員身分執行的視窗輸入文字。如需在這類視窗手寫，請同樣以系統管理員身分執行 TouchWrite。

兩指滑動時，頁面也跟著捲動了？

部分程式（例如瀏覽器）會直接處理觸控板的兩指捲動，所以兩指滑動手勢可能同時讓頁面捲動一下。

設定保存在哪裡？

設定檔存放在 %APPDATA%\TouchWrite\settings.json，包括快捷鍵、辨識引擎、輸出字形、自動輸入與面板大小等選項。
