01

學習管理

ClassFlow

▦

Android · Nextcloud

課表、作業與考試，一起安排。

以 Nextcloud 為同步中心的課表與校園日程管理工具。在 Android 與網頁端管理固定每週課程、作業、考試及活動，離線時也能繼續使用。

下載 / 安裝 ↗使用說明與原始碼 ↗

Android App 搭配 Nextcloud ClassFlow App 使用。

  • 每週課表

    整理固定課程，將作業、考試與活動連結至課堂。

  • 跨端管理

    Android 與 Nextcloud 網頁端共用課表和日程。

  • 隨身提醒

    離線資料、背景同步、本機提醒與桌面小工具。

02

桌面工具

Secondary

⊞

Windows 11

讓第二個螢幕，成為你的控制中心。

把時鐘、行事曆、便箋、快捷方式與系統資訊放在副螢幕。依照自己的使用習慣排列組件，在日常桌面與遊戲模式之間切換。

下載 / 安裝 ↗使用說明與原始碼 ↗

適用 Windows 11 x64；發行包包含所需的 .NET 執行環境。

  • 自由組件

    拖動、縮放與排列時鐘、待辦、媒體及其他首頁組件。

  • 快捷導航

    集中管理程式、檔案、資料夾與網站，支援分組和搜尋。

  • 遊戲模式

    查看系統負載與監測資訊；可用資料取決於硬體及系統權限。

03

檔案傳輸

QRTrans

⌗

Android · Windows

讓資料透過光，抵達另一台裝置。

將檔案或文字轉為連續變化的 QR Code，再用另一台裝置的相機接收。整個傳輸過程不需要網路、帳號或雲端服務。

下載 / 安裝 ↗使用說明與原始碼 ↗

Android 支援傳送與接收；Windows 版本支援傳送。

  • 離線傳送

    支援最大 64 MB 的單一檔案與 UTF-8 文字。

  • 容忍丟幀

    可從 QR Code 輪播中途開始掃描，支援修復缺失資料。

  • 密碼保護

    可選擇加密傳輸，並透過 SHA-256 驗證接收內容。

04

照片管理

NextPhoto

▧

Android · Nextcloud

自己的照片，放在自己的雲端。

為 Nextcloud 相片打造的 Android 圖庫。用日期分組瀏覽照片與影片，管理雲端相簿、備份手機照片，也能保存離線副本。

下載 / 安裝 ↗使用說明與原始碼 ↗

需要 Android 10 或以上，以及使用 HTTPS 的 Nextcloud 伺服器。

  • 沉浸瀏覽

    日期分組、照片格狀排列、縮放檢視與影片播放。

  • 相簿與備份

    同步 Nextcloud Photos 相簿，提供手動與自動備份。

  • 私密相簿

    加密相片與影片，支援密碼或指紋解鎖。

05

筆記工具

CloudNotes

≡

Android · Nextcloud

離線記下想法，回到雲端同步。

連接自己的 Nextcloud Notes，在手機上建立、整理與編輯筆記。提供 Markdown 編輯與預覽，並能為個別筆記加上密碼保護。

下載 / 安裝 ↗使用說明與原始碼 ↗

需要 Android 8.0 或以上，以及啟用 Notes 的 HTTPS Nextcloud 伺服器。

  • 隨時編輯

    下載後的筆記可離線閱讀與修改，支援手動及背景同步。

  • 整理內容

    搜尋、分類、收藏與 Markdown 編輯工具。

  • 個別加密

    以密碼保護筆記內容，可選擇啟用指紋解鎖。

06

遊戲工具

MPad

✣

Android · Windows

把手機，變成你的遊戲手把。

用 Android 手機觸控控制 Windows 遊戲。透過區域網路或藍牙連接電腦伴侶程式，將輸入轉換成 Xbox 360 / XInput 手把訊號。

下載 / 安裝 ↗使用說明與原始碼 ↗

需要 Android 9 或以上；Windows 伴侶模式需安裝 ViGEmBus 驅動。

  • 完整操作

    雙搖桿、十字鍵、類比扳機與完整按鈕配置。

  • 自訂配置

    調整位置、大小、透明度、死區與靈敏度，支援多點觸控。

  • 多種連線

    區域網路、藍牙伴侶與藍牙 HID 模式；伴侶模式支援震動回傳。

07

氛圍時鐘

Beautiful Waste

◷

Windows

時間、光，還有一點留白。

一個專注於視覺氛圍的 Windows 桌面時鐘。柔和光霧持續流動，搭配時間、日期與輪換短句，適合放在閒置螢幕上。

下載 / 安裝 ↗使用說明與原始碼 ↗

適用 Windows 10/11，需可用的 DirectX 12 或 Vulkan 圖形驅動。

  • 柔和光霧

    原生圖形渲染的動態背景，支援速度與時鐘大小調整。

  • 自己的節奏

    切換字體、時間格式與短句，也能匯入自己的語句。

  • 桌面陪伴

    全螢幕顯示、媒體控制與本機偏好設定保存。
